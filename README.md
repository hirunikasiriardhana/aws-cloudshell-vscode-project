# AWS CloudShell & VS Code IDE Project

## Overview
A hands-on project using AWS CloudShell and VS Code IDE (code-server) 
to work with AWS CLI and Boto3 (AWS SDK for Python).

## What I did
- Listed S3 buckets using AWS CLI and boto3 from CloudShell
- Uploaded files from CloudShell to an S3 bucket
- Connected to VS Code IDE (code-server) running on EC2
- Installed boto3 (pip3 install boto3)
- Ran a Python script to programmatically list S3 buckets
- Created an index.html file and uploaded it to S3 for hosting

## Skills demonstrated
- AWS CLI
- AWS SDK for Python (Boto3)
- Amazon S3
- Cloud-based IDE (VS Code / code-server)
